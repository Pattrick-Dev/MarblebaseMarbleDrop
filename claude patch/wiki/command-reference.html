Command Reference

All commands below are player-facing subcommands of /md.

Command Purpose
/mdOpen the help and overview menu.
/md tasksView and track daily and weekly tasks.
/md dustCheck your Dust balance.
/md tableOpen the Infusion Table.
/md infusiontableAlias for opening the Infusion Table.
/md upgradeOpen the Upgrade Station.
/md upgradesAlias for opening the Upgrade Station.
/md recyclerOpen and use the Recycler.
/md recycleAlias for using the Recycler.
/md raceOpen the race menu and pick a track.
/md racesAlias for opening the race menu.
/md joinJoin the current scheduled server race (hold a marble first).
/md leaveLeave whatever race you're entered in and get your marble back.
/md race nextCheck if a scheduled race is open, running, or how long until the next one.
/md teamChoose your marble team.
Staff-only commands are intentionally not listed on this player wiki.
Use /md as your starting point whenever you forget where a feature lives.
