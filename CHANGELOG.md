# Changelog

## Races

- Real physics - races now have actual gravity, bounce, and cornering instead of the old simplified movement.
- New race abilities: pick a Loadout before racing, use Boost for a speed burst, and Glow to highlight your marble.
- Scheduled races now run at fixed times (12:00, 16:00, 20:00, 00:00) instead of a recurring timer - entry is always open until the next one starts.
- The boss bar shows how many players have joined.
- The server MOTD shows the race countdown/status.
- Discord now posts and live-updates race status.

## Marble Display (new)

- Place your marbles as blocks to show them off.
- Only you (or an admin) can break your placed marble, and breaking it gives you back the exact same marble.
- Right-click your placed marble for a settings menu: toggle the hologram, toggle rarity display, and pick from 16 particle styles.
- Placed marbles are now protected from explosions and pistons.

## Infusion

- Marbles can no longer be used as catalysts - only crafting materials.
- Catalysts now have a capped value shown right in the infusion table, so you always know exactly how much a catalyst (or stack of them) is worth before you use it - stacks worth more than the cap are refused instead of wasting the extra.
- Rebalanced catalyst values across the board so catalysts can no longer buy the best odds outright.

## Tasks

- Daily and weekly tasks are now drawn from a much bigger pool, so you won't see the same fixed list every reset.

## Fixes

- Hidden tutorial players no longer look disconnected in the tab list.
- Fixed the tutorial's crafting item preview showing wrong on some walls.

## New Commands

- **`/recipes`** - browse every station's crafting recipe in one menu.
